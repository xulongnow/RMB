# 人民币大写转换工具

一个纯前端的人民币金额大小写转换网页工具，支持小写金额与大写金额之间的双向转换。

## 功能特性

- **小写转大写**：输入阿拉伯数字金额，实时显示中文大写金额
- **大写转小写**：输入中文大写金额，转换为阿拉伯数字
- **实时转换**：小写输入即时响应，无需手动点击
- **一键复制**：转换结果一键复制到剪贴板
- **一键清空**：快速清空输入内容
- **「人民币」前缀开关**：可选是否在结果前添加「人民币」
- **转换历史**：自动保存最近 10 条转换记录，支持还原和清空
- **输入校验**：非法字符即时提示，金额上限千亿位
- **大写规范速查**：内置汉字对照表和书写规则说明
- **移动端适配**：响应式布局，手机端友好

## 转换规则

遵循人民币大写书写规范：
- 到「元」为止写「整」（或「正」）；有分的不写整
- 中间有 0 写「零」
- 连续多个 0 只写一个零
- 角位是 0 而分位不是 0 时，元后写「零」

## 使用方式

直接在浏览器中打开 `index.html` 即可使用，无需网络连接。
